Sobre o BlueShield

O BlueShield nasceu com um objetivo claro: democratizar o conhecimento sobre cibersegurança. Num mundo cada vez mais digital, as ameaças informáticas evoluem todos os dias, mas a maioria das pessoas não tem acesso a informação clara e simples sobre como se proteger.

Esta plataforma foi criada no âmbito de um projeto académico, mas com a ambição de se tornar uma referência educativa. Aqui, qualquer pessoa – desde um utilizador doméstico a um profissional de TI – pode:

  • Explorar um catálogo organizado das principais vulnerabilidades (Trojan, Phishing, Ransomware, etc.)
  • Compreender, de forma simples, como cada ameaça funciona e quais os seus riscos
  • Aprender medidas práticas de mitigação – o que fazer para evitar ser vítima
  • Consultar um ranking das ameaças mais perigosas com base na sua relevância
  • Pesquisar e filtrar conteúdos de acordo com o nível de risco (Alto, Médio, Baixo)

O BlueShield não é apenas um diretório de vulnerabilidades. É um convite à literacia digital. Acreditamos que a melhor defesa contra ataques cibernéticos é o conhecimento. Por isso, todo o conteúdo foi redigido em linguagem acessível, evitando jargão técnico excessivo, e acompanhado de conselhos úteis para o dia a dia.

Como funciona tecnicamente?

Por detrás desta interface moderna, o BlueShield é alimentado por tecnologias sólidas:

  • Django 5 – framework web que garante robustez e segurança.
  • MySQL 8 – base de dados relacional para armazenar as vulnerabilidades.
  • Docker & Docker Compose – permitem executar o projeto em qualquer ambiente com um simples comando.
  • Gunicorn – servidor WSGI de produção.
  • Tailwind CSS + Font Awesome – design responsivo, moderno e com ícones.

O código está disponível publicamente no GitHub, promovendo transparência e aprendizado.

Para quem é este projeto?

Para estudantes de cibersegurança, profissionais de TI que desejam um material de consulta rápida, e para qualquer cidadão que queira navegar na internet com mais confiança. Não é necessário qualquer conhecimento prévio – a informação está organizada de forma intuitiva.
